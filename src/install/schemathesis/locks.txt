# aarch64, glibc or musl). uv installs a block with --require-hashes, so a
# file whose hash isn't listed, or a package the block doesn't pin, fails the
# install before anything runs. Schemathesis needs Python 3.11 from 4.31.0

#   src/install/lock.sh -t schemathesis -v <version>

# minor version and moves the pin often, so the lock resolves both together.
